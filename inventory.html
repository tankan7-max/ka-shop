Inventory — Virtual Snack Shop

Stock on hand for every snack. ← Back to the shop

How this goes live Change the numbers below, then press Download inventory.json. Upload that file to the shop's repository (GitHub → ka-shop → Add file → Upload files, replacing the old inventory.json), or send it to Muse to push. The shop reads it when the page loads, so the new stock shows up after the site rebuilds (about a minute). A snack at 0 shows as “Out of stock”, cannot be added to the cart, and its shelf space stays empty.

Stock is kept in inventory.json next to the shop page. The shop treats a snack missing from that file as in stock.
