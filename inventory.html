How live stock works The shop reads its stock from the database, so anything you Save to the shop here shows for customers within 20 seconds — no file to upload.
When a customer presses Checkout, their snacks are set aside for them while they pay. If they never send the order, the snacks go back on sale by themselves. Once they send the order it appears under Orders waiting for you and stays set aside until you decide: Paid — take off stock when you see the payment (match the reference), or Release to put the snacks back on sale.
“I’ve paid” is only the customer’s word — check your bank before packing.
Download backup saves the numbers as inventory.json. The shop falls back to that file if the database cannot be reached, so upload a fresh copy to the repository now and then.
How this goes live Change the numbers below, then press Download inventory.json. Upload that file to the shop's repository (GitHub → ka-shop → Add file → Upload files, replacing the old inventory.json), or send it to Muse to push. The shop reads it when the page loads, so the new stock shows up after the site rebuilds (about a minute).
A snack at 0 shows as “Out of stock” and cannot be added to the cart. Customers cannot order more of a snack than you have, and the shelf shows “Only N left” when stock is low.
Stock does not go down by itself. When an order comes in, use Record an order below (or the − buttons), then download and upload the file. Nothing on this page changes the live shop until that file is uploaded.
Record an order by hand (take its items off the stock) For orders that did not come through the shop's checkout. Paste the order message a customer sent you. Every “2 × Snack name” line is taken off the stock.
