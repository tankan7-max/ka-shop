Inventory — Virtual Snack Shop

Stock on hand for every snack. ← Back to the shop

How this goes live Change the numbers below, then press Download inventory.json. Upload that file to the shop's repository (GitHub → ka-shop → Add file → Upload files, replacing the old inventory.json), or send it to Muse to push. The shop reads it when the page loads, so the new stock shows up after the site rebuilds (about a minute).
A snack at 0 shows as “Out of stock” and cannot be added to the cart. Customers cannot order more of a snack than you have, and the shelf shows “Only N left” when stock is low.
Stock does not go down by itself. When an order comes in, use Record an order below (or the − buttons), then download and upload the file. Nothing on this page changes the live shop until that file is uploaded.
Record an order (take its items off the stock) Paste the order message a customer sent you. Every “2 × Snack name” line is taken off the stock.
